# Vaka V6.8.2

## Главное
- Недельная активность закрывается в понедельник в 04:10 МСК.
- Коины за активность выдаются только при закрытии недели: 100 итоговой недельной активности = 60 🪙.
- Недельная активность добавляется к `total_activity` только один раз при rollover.
- Повторный rollover не дублирует ни активность, ни коины.
- Титулы считаются по активности за всё время.
- Обновление FF-профиля не изменяет недельную или lifetime-активность.

## Панель
- Новый пользовательский дизайн панели.
- Все административные кнопки перенесены внутрь `👑 Админ-панель`.
- Владелец видит `🪙 Редактор коинов`: выбор игрока по нику → установка баланса.
- `/setcoins TELEGRAM_ID КОЛИЧЕСТВО` доступна только владельцу.

## Telegram-ссылки
- В рейтингах, отчётах и списках рядом с ником показывается кликабельный Telegram-профиль.

## Модерация
- `/warn`, `/warnings`, `/mute`, `/unmute`, `/ban`, `/unban`, `/unwarn`, `/kick`.
- Магазин: снятие всех блокировок, бана, мута и варнов.

## Магазин
- Покупки доната/буста отправляют уведомление владельцу.
- `БОТ ДЛЯ ЛВЛ` не списывает коины и сообщает: «Бот находится в разработке».

## Импорт активности
- Автоматическое распознавание списка активности работает только в мониторинговом чате `GUILD_CHAT_ID`.

## Вака
- Убран «Кто сильный».
- Добавлен формат `Вака <вопрос>` для нейросети.
- При отсутствии/ошибке AI: `😴 Вака устал от вопросов`.

## Структура
- Удалены старые вложенные исходники V6.7, runtime-логи, pycache, старые RAR и дублирующие runtime-файлы БД из дистрибутива.
