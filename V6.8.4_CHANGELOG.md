# Vaka V6.8.4

- Строгий протокол VAKA_MONITORING_V1 для игрового/ADB-мониторинга.
- Автоматический импорт списков активности принимается только из MONITORING_CHAT_ID.
- Повторные снимки в течение недели обновляют только недельную активность; lifetime и коины не меняются.
- Коины начисляются один раз в понедельник 04:10 МСК за итог предыдущей недели: 100 активности = 60 коинов.
- Lifetime увеличивается только при недельном rollover. Титулы считаются по lifetime.
- Турнирные строки поддерживаются в мониторинговом протоколе.
- Антинакрутка сравнивает текущие снимки, фиксирует аномалии и уведомляет владельца, не изменяя данные.
- Добавлена таблица истории снимков мониторинга.
- MONITORING_CHAT_ID вынесен в .env.
