Vaka V8.0.1 — Release Verification

Changes in this maintenance release:
- Fixed Participant Panel -> 🏆 Рейтинг callback crash.
  Root cause: weekly-player query did not include players.total_activity,
  while the rating renderer accessed that field.
- /ff now sends the SiamBhau generated profile banner after the text profile.
- /ff now exposes additional non-secret FreeFireInfo fields when present:
  max ranks, badge count, pin, release version, title, banner/headPic IDs,
  pet info, social signature/language/gender and credit score.
- /ffoutfit UID added for the SiamBhau 1024x1024 outfit renderer.
- Guild member/capacity merge no longer overwrites valid FreeFireInfo values
  with zero values from a partial guild response.
- Supplied guild_activity(3).db data was merged into the release DB while
  preserving release-only schema tables (guild_applications, kv_matches,
  marriages, rp_actions).
