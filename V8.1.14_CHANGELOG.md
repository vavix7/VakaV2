# V8.1.14 — Weekly activity → coins → lifetime integrity

- Verified weekly rollover: weekly activity is added to lifetime `players.total_activity` exactly once when the week closes.
- Verified coins: every full 100 weekly activity points awards `ACTIVITY_COINS_PER_100` coins (default 60), exactly once per player/week.
- Preserved weekly remainder activity in lifetime; only full 100-point units generate coins.
- Added a guard preventing manual edits to an already rolled-over week, which prevents lifetime/coin totals from becoming inconsistent after closure.
- No existing RP, 18+ RP, commands, panels, or database records are removed.
