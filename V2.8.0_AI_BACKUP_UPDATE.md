# V2.8.0 AI + Backup update

- Рабочая база: Vaka V2.8.0.
- Старый функционал не удалён.
- Резервные копии: максимум 3 последних файла `guild_activity_*.db`. При создании нового бэкапа удаляются самые старые копии сверх трёх.
- AI получает единый системный prompt с контекстом гильдии.
- Уровень гильдии берётся из `FF_GUILD_LEVEL`, если задан.
- Количество участников гильдии в игре берётся из `FF_GUILD_MEMBERS`, если задан; если нет — Вака не выдумывает значение.
- Количество зарегистрированных пользователей берётся из текущей БД динамически.
- Актуальные тексты правил гильдии и КВ добавляются к системному контексту из существующих констант бота.
- Один и тот же системный prompt используется Gemini, Groq, Mistral, Cloudflare и OpenRouter.
