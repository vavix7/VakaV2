# V8.1.13 — Command routing repair

## Command routing
- Fixed the broad RP compatibility handler so ordinary commands are no longer swallowed.
- Existing slash handlers remain intact; the unified bridge reuses them instead of replacing them.
- Added complete RU/EN no-slash aliases for the existing command set where missing.
- Added RU/EN aliases for `/mystats`, `/myactivity`, `/sayall`, `/stopchat`, `/startchat`, `/clearall`, and `/kvrosters`.
- Added natural-language aliases: `моя статистика`, `моя стата`, `моя активность`, `сказать всем`, `стоп чат`, `запуск чат`, `снять все ограничения`, `убрать все ограничения`, `состав КВ`.

## New command implementations where no legacy handler existed
- `sayall` — management-only announcement command.
- `stopchat` / `startchat` — management-only chat lock/unlock.
- `clearall` — management-only removal of ban, mute and active warnings for a selected user.
- `mystats` — personal statistics for the registered participant.
- `myactivity` — personal activity summary.

## Permissions
- Manual chat cleanup is now restricted to management ranks 6–8, matching the project requirement.

## Preservation
- Existing RP_ACTIONS, RP_ALIASES and IRIS_EXTRA_RP dictionaries are unchanged.
- Existing 18+ RP vocabulary is unchanged.
- Existing handlers and legacy command implementations are preserved.
- Existing database/data/guild_activity.db is preserved; no rows are deleted by this release.
