# Vaka V8.0.0

## Release focus
- SiamBhau Premium API is now the primary Free Fire API.
- Default Free Fire region is BD; IND is retried automatically when BD returns no player profile.
- `/ff` uses the SiamBhau full profile endpoint and additionally fetches BR/CS stats and Ban Check.
- Added `/ffstats`, `/guildinfo`, `/bancheck`, and `/ffapi` diagnostics.
- Guest panel follows the requested layout: Registration / Guild Request, Assign KV / About, Help.
- Participant panel includes KV and guild-request access.
- Admin panel includes KV management and guild applications.
- Approved KV proposals are published to `GUILD_CHAT_ID` with enemy guild, enemy roster, our roster, date/time and purpose.
- Uploaded SQLite database was restored from the supplied DB + WAL and checkpointed; no activity/player data was discarded.
- Added offline release verification for Python syntax, SQLite integrity, callback coverage and API configuration.

## Intentionally excluded Iris modules
Duels, Cubes, Clans, Circles, Relationships, Reputation, Rewards, Bookmarks, Notes, Timers, Catalog, Iris Exchange, Inline mode, Business Bot, Reports, Giveaways, Telegram integration, and Iris blacklist.

## V8.0.1 maintenance fix
- Fixed the broken 🏆 Рейтинг panel button caused by a missing `total_activity` column in the weekly ranking query.
- `/ff` now sends the SiamBhau profile banner and exposes additional profile metadata.
- Added `/ffoutfit UID` for the SiamBhau outfit renderer.
- Preserved the supplied database records while retaining the release-only tables required by Vaka features.
