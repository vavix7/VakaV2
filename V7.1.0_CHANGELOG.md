# Vaka V7.1.0

Полная доработка по спецификации Vaka/Iris-style:
- единый no-slash command dispatcher с longest-match aliases и `/`-вариантами;
- строгая проверка прав для административных команд;
- гостевая панель: гильдия, правила, регистрация, заявка, КВ, соцсети;
- заявки на вступление с уведомлением руководства и кнопками принятия/отклонения;
- КВ: максимум 3 активных слота, формат 4×4, дата, время, назначение, обе команды;
- пошаговое предложение КВ незарегистрированным пользователем;
- браки с подтверждением второй стороны и разводом;
- расширенный неявно-сексуальный/юмористический RP-модуль; графические сексуальные действия не включаются;
- варны 7 дней и автоматическое ограничение после 5 активных варнов;
- правило-aware варны: `правило N` связывается с правилами 1–10;
- Free Fire profile card показывает недельную активность и статус;
- уровень гильдии и число участников берутся из FF API в существующем профиле;
- off-host Telegram backups по расписанию, без попытки использовать Telegram/Drive как живую SQLite БД;
- существующая база Vaka сохранена и используется как основа миграции.

Исключённые Iris-модули не добавлялись: дуэли, кубы, кланы, кружки, отношения, репутация, закладки, заметки, таймеры, каталог, биржа, inline, розыгрыши и чёрный список Iris.
